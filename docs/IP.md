# NYC 212 Invader — Intellectual Property

## Brand

**NYC 212 Invader** is original project IP. Use this name and future original art/audio only.

Do **not** use:

- "Space Invaders" name or logo
- Taito invader sprite designs
- Classic invader sound effects
- Any trademarked arcade branding implying official tie-in

We are **inspired by** arcade shooters, not a clone of a protected franchise.

## Third-Party Assets Checklist

When adding any external asset:

1. Confirm license allows web game use
2. Add entry to attribution manifest
3. Note in PR / commit if asset changes
4. Prefer CC0 / MIT / custom commissioned work

## Enforcement Posture

If unsure whether an asset is too close to Space Invaders or another IP:

- **Do not ship it**
- Replace with original placeholder
- Ask for review before v1.0 public marketing
